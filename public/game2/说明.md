# 星愿宇航员 · 生日大冒险

这是一个纯前端像素风网页小游戏。玩家操纵宇航员收集 6 枚星光，躲避或射击从右侧飞来的陨石；收集完成后穿越虫洞，为巨大生日蛋糕点燃蜡烛并播放生日祝福。

## 文件结构

```text
cosmic-birthday-game/
├── index.html                         # 完整游戏源码（HTML、CSS、JavaScript）
├── 说明.md                            # 本说明文件
├── assets/
│   ├── cosmic-atlas.png               # 宇航员、虫洞、蛋糕素材图集
│   ├── happy-astronaut.png             # 收集星光后的 Happy 状态角色
│   └── astronaut-character-reference.png # 最初的角色设定参考图
└── font/
    ├── fusion-pixel-12px.woff2        # 中文像素字体
    └── FUSION_PIXEL_FONT_LICENSE.txt  # 字体授权说明
```

## 如何运行

游戏没有构建步骤，也不需要安装依赖。

### 方法一：直接打开

双击 `index.html` 即可尝试运行。部分浏览器可能会限制本地音频或字体加载，如果出现此情况，请使用下面的本地服务器方式。

### 方法二：启动本地服务器（推荐）

在项目目录中打开终端，运行：

```bash
python -m http.server 8000
```

然后在浏览器打开：

```text
http://localhost:8000
```

也可以使用 VS Code 的 Live Server 等静态网站工具。

## 操作方式

- `WASD` 或方向键：移动宇航员
- `Shift`：加速飞行
- `空格` 或 `J`：发射能量弹
- 手机和平板：使用画面下方的方向键、加速和发射按钮

## 游戏流程

1. 收集宇宙中的 6 枚星光。
2. 每收集一枚星光，宇航员会短暂切换为 Happy 状态。
3. 躲避迎面而来的陨石，或开枪将其击碎。
4. 收集全部星光后，飞入右侧出现的虫洞。
5. 穿越虫洞后，飞到蛋糕蜡烛的位置将其点亮。
6. 点亮蜡烛后播放生日音乐与祝福。

## 修改名字和生日祝福

玩家可以在开始界面直接输入寿星昵称。

如需修改默认祝福文案，打开 `index.html`，搜索下面这段文字并替换：

```text
愿你的新一岁像星河一样闪耀，永远有勇气奔向喜欢的宇宙，也总有人为你点亮归航的灯。
```

## 修改游戏参数

所有玩法逻辑都位于 `index.html` 底部的 `<script>` 中：

- `shards`：星光的位置和数量
- `meteors`：初始陨石的位置、尺寸与速度
- `accel` 和 `max`：宇航员加速度与最大速度
- `fireShot()`：射击速度和射击间隔
- `birthdayTune()`：生日音乐音符与节奏

修改后保存并刷新浏览器即可查看效果。

## 替换图片素材

可以直接替换 `assets` 文件夹内的同名 PNG 文件。建议保持透明背景与原图尺寸比例，以免角色或蛋糕在画面中发生偏移。
